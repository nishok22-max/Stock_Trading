# Stock Trading App

A simulated stock trading application built as a team project.

## Shared stack

- Frontend: Astro.js
- Backend: Java 21 and Spring Boot
- Build: Maven
- API: REST and JSON
- Storage: in-memory collections
- Money: BigDecimal
- Testing: JUnit 5 and Postman

The `main` branch is the starting point for shared team development. Each member's module is developed on a separate feature branch.

Member 3's Order Management and Trading Engine implementation is available on [`feature/member-3-trading-engine`](https://github.com/nishok22-max/Stock_Trading/tree/feature/member-3-trading-engine).
